# 실기 검증 보류·이관

2026-10-09 사용자 지시: 실기 검증을 현재 진행할 수 없으므로 별도 실기 테스트 이슈로 남긴다. [실기 테스트 #11](https://github.com/wotjr1649/U2BIO.LabelPrinting/issues/11)을 생성하고 TASK-07의 후속 관계를 확인했다. 이 문서는 시험 실행 기록이 아니다.

## 개발 완료와 실기 완료

TASK-05/07은 소프트웨어 구현·관리/합성 검사·파일 배포/정적 검사·문서 근거로 완료 범위를 정리한다. TASK-08의 DB 없는 Tester와 TASK-09 연동 예제를 진행할 수 있다. 별도 이슈 생성/이관이 실제 SDK 로드·ABI·장치·배출·오류 실기 통과를 뜻하지 않는다. 실제 제품 지원·운영 인수에는 보류한 실기 근거가 여전히 필요하다.

runtime의 SDK 파일/버전/아키텍처/로드 보호, 미검증 transport·글꼴 차단, RFID 명령 거부, 사전검사·실패/불명·취소·timeout/pending·소유권·정리 계약은 유지한다. 코드·tests·보호 정책을 변경하거나 합성 성공으로 실기를 대체하지 않는다. 공통 DLL 검증 후 UI를 만드는 순서는 유지하며 그 선행 범위를 소프트웨어 인수로 구분한다.

## #11에서 재개할 범위

- 고정 SDK x86/x64 runtime 로드·ABI, 명시 USB 대상의 연결·상태·해제·재연결.
- 실제 사전검사의 인쇄/이송 미호출, 영문·한글 단건의 장수·위치·가독성·배출 관측.
- 다건·오류/불명·취소/Dispose·늦은 응답·pending·소유권/정리의 실제 동작.
- 용지/리본/헤드/연결/timeout 오류와 안전하게 재현 가능한 loader/export/vendor 충돌 경계.
- 장치/firmware 확인 상태, SDK/OS/ANSI/용지/글꼴/transport별 실제 지원·미실행/제외 범위.

펌웨어나 조건을 확인할 수 없으면 미확인으로 기록한다. 특정 시험용 규격·7.5mm offset·15mm 배출을 DLL 공통값으로 고정하지 않는다. RFID 리더·앱·재태깅·저장값 전후 실측을 새 필수 시험으로 복원하지 않는다. TASK-02의 과거 실기를 새 Bt003Printer 경로의 실제 검증으로 바꾸지 않는다.

## 재개 조건과 기록

#11은 현재 열린 보류 상태다. 실제 시험 재개는 사용자의 별도 지시와 장치/라벨/실행 범위를 확인한 뒤 진행한다. SDK 외부 로그·캐시 기록 등은 그 실행 시점의 허용 범위를 확인한다. 이 등록은 SDK·장치·출력·이송·DB·push/merge·배포/릴리스 실행 허용이 아니다.

작업 revision·SDK 해시·아키텍처·장치/펌웨어·라벨 규격·날짜·함수/결과·실제 관측과 미실행 사유를 기록한다. 환자/RFID 실제 값·원문 SDK 로그·인증 정보·로컬 절대 경로를 외부 이슈에 게시하지 않는다. [후속 #10](https://github.com/wotjr1649/U2BIO.LabelPrinting/issues/10)은 더 넓은 미검증 경계/지원 추적을 유지하고 #11의 장치 증거를 연결하여 같은 시험을 중복하지 않는다.

## 2026-10-12 TXT 범위의 일부 재개

사용자 지시로 연결 상태 결함 수정과 TXT 공개 API 실기를 #14에서 재개했다. [현재 결과](TXT_PUBLIC_API_VALIDATION.ko.md)는 관리 검사와 실제 문구·배출 관측을 구분한다. 배출15mm 첫 시험은 SDK응답0·배출 정상이나 잉크 없음으로 실제 인쇄 실패다. 문구·자동 복귀·x86 및 넓은 #11 조건은 아직 완료되지 않았다. JSON/XML의 이번 테스트·검수·검증은 DEFERRED다. 위 최초 이관 근거와 과거 실기 완료 경계는 유지한다.
